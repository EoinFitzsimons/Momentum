# Usability Test Plan & Report (Placeholder) — Momentum IA

Purpose: validate the IA, navigation, and key flows for the midpoint build.

Participants: 3–5 teammates or target users
Method: remote or in-person, moderated; screen share

Tasks (aligned to flows)
1) Start a race from the Dashboard using defaults.
2) Hire a driver from the list.
3) Apply one upgrade in the Garage.
4) Find latest standings/results after a race.

Metrics
- Task success (Y/N) and time on task
- Misclicks or backtracks
- Comments/confusion points

Success criteria (pass/fail guidance)
- Start race: <= 3 clicks from Dashboard; no blockers
- Hire driver: find Hire/Offer in <= 2 clicks from Driver Detail; filters discoverable
- Upgrade: user finds Garage and applies or understands stub without confusion
- Standings: reachable in <= 2 clicks post-race

Post-test
- Collect top 5 issues and map to fixes (labels, CTA placement, nav ordering)
- Decide if any menu items should be hidden until functional (e.g., Reports/Store if stubbed)

- Placeholder ready; run sessions and fill in results table and issues list.
