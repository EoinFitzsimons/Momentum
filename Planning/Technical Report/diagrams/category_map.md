Rationale

- The full project supports multi-discipline championships, persistent career progression, and admin tooling for data import and validation. This map aligns to the use cases in the technical report and to the backend schema.

Secondary groupings (common screens and actions)

- Dashboard: session summary, quick start CTAs, next event, recent results
- Drivers: driver list, driver profile, contracts, hire/offer, retirement and progression
- Teams: team list, team profile, budget and staff, hire/fire staff
- Garage and Vehicles: car setup, upgrades, loadouts, component health and maintenance
- Staff and Contracts: staff list, staff detail, salary management, role assignments
- Race and Calendar: race setup, race live (visualisation), session management, practice/qualifying/race
- Championships: create/manage championship, points system, calendar generation
- Tracks and Circuits: import/edit circuits, track properties, surface types
- Standings and Results: per race, season standings, driver/team tables
- Reports and Telemetry: telemetry exports, filters, statistical analysis, performance graphs
- Store and Upgrades: purchasable parts, bundle management, purchase flow (can be stubbed for demo)
- Settings: user preferences, display, accessibility
- Help and Documentation: FAQ, glossary, onboarding hints
- Admin Tools and Data Import: procedural generation tools, import circuits, name validation, database utilities

Priority tiers (project scope and phasing)

- Priority A (Core MVP): Dashboard, Race Setup, Race Live, Standings and Results, Drivers (read + select), Tracks import
- Priority B (Career depth): Teams, Garage and Vehicles, Staff and Contracts, Championships, Calendar automation
- Priority C (Advanced/Polish): Reports and Telemetry, Store and Upgrades, Admin Tools enhancements, extensive data validation

CTA placement and UX guidance

- Dashboard: Start Race, Create Championship, Quick Select Driver or Team, Import Data
- Drivers / Teams: Hire, Offer Contract, View Profile, Quick Hire from list
- Garage: Apply Upgrade, Save Loadout, Preview Performance Impact
- Race Setup: Start Race, Adjust Race Length and Conditions
- Race Live: Pace and overtake controls, Pit request, Return to Dashboard, View Telemetry
- Standings: Export Results, Drill into Race Detail

Traceability to use cases

- This category map maps directly to the use cases in the technical report. For example: UC-1 Read Driver Details maps to Drivers -> Driver profile, UC-3 Create Race Result maps to Race -> Race Live and Standings, UC-7 Create Race Event maps to Championships -> Calendar.

Use this as the canonical navigation map for the full project. For the midpoint deliverable, extract Priority A screens and reduce the navigation accordingly.
