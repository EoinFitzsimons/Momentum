- Garage

Secondary groupings

- Standings / Results: Latest Race, Season Table

Priority tiers
- Priority A: Dashboard, Drivers, Garage, Race Setup, Standings/Results
- Priority B: Calendar, Store, Reports (if functional), Driver Detail
- Priority C: Settings, Help

CTA placement
- Dashboard: Start/Enter Race, Hire, Upgrade
- Drivers: Hire/Offer from list and detail
- Garage: Upgrade/Apply
- Race Setup: Start Race
- Standings: View Race Detail
