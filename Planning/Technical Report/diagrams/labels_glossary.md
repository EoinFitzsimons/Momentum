# Labels Glossary — Momentum IA (Midpoint)

Consistent labels for nav, actions, and data terms.

Navigation labels
- Dashboard — Home landing
- Drivers — List of all drivers
- Driver Detail — Individual driver page
- Garage — Upgrades and car status
- Race Setup — Configure lineup/strategy for next race
- Race (Live) — Live race view
- Standings / Results — Tables and latest race outcomes
- Calendar — Upcoming races/championship dates
- Reports — Analytics/telemetry (advanced)
- Store — Upgrades/storefront
- Settings — Preferences
- Help — FAQ/Glossary

Action labels
- Start Race / Enter Race — Primary CTA to begin a race
- Hire — Offer a contract to a driver (do not use “Sign”/“Contract” interchangeably)
- Offer — Action to propose terms to a specific driver
- Upgrade — Apply or purchase an improvement
- Save Setup — Save race setup defaults
- View Standings — Jump to standings/results

Data/field labels
- Budget — Current available funds
- Next Race — Location/date of upcoming event
- Contract Status — (Free Agent | Active | Expiring)
- Skill Ratings — Use consistent metric names across lists and detail pages
- Telemetry — Lap/sector data and performance metrics

Notes
- Prefer verbs for buttons (Hire, Upgrade, Start Race).
- Keep labels short; avoid jargon on primary paths; add tooltips for advanced metrics.
