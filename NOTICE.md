# Third-Party Notices

This file records third-party software, data, fonts, audio, images, and other
assets included in Momentum releases. Each release should update this file to
match the exact files shipped with that release.

## Software dependencies

The dependency list is maintained in `Momentum/Python/requirements.txt`.
Before distributing a release, record the installed versions and the license
notice for every direct and transitive dependency here.

In particular, review the current commercial distribution terms for PyQt6.
PyQt6 is commonly offered under GPLv3 or a separate commercial license; a
closed-source commercial build may require a commercial PyQt license.

## Included assets

Every image, font, sound, logo, dataset, and generated or downloaded asset
must have a recorded source, author, license, and attribution requirement
before it is included in a release.

No third-party asset should be assumed to be reusable merely because it was
found online.
